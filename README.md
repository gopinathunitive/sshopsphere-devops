# ShopSphere DevOps Lab

## Objective

Build, deploy, automate, monitor and troubleshoot an e-commerce REST API over 60 days.

## Planned stack

* Node.js and Express
* PostgreSQL and Redis
* Docker and Docker Compose
* Linux, Bash and Nginx
* GitHub Actions
* Cloud infrastructure and Terraform
* Kubernetes fundamentals
* Monitoring, logging and backup/recovery

## Team

* Person A: Infrastructure and operations
* Person B: Containerization and automation
* Both members must learn and demonstrate both responsibilities.

## Engineering rules

* Keep secrets out of Git.
* Document setup and deployment steps.
* Test changes before marking tasks complete.
* Record failures, root causes and fixes.
* Prefer reproducible automation over manual repetition.
